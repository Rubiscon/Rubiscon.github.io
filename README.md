# Rubiscon.github.io

Personal homepage styled after WordPress [Twenty Twenty-Five](https://wordpress.org/themes/twentytwentyfive/), using the same home layout as [Silver Sky Studio Blog](https://blog.silversky.moe/) (compact header + full post loop + footer).

## Structure

- `index.html` — static blog home
- `twentytwentyfive/` — official theme package (fonts, sample images, `theme.json` reference)
- `twentytwentyfive/assets/css/style.css` — static CSS port for GitHub Pages

## Local preview

Open `index.html`, or from the repo root:

```bash
npx --yes serve .
```
